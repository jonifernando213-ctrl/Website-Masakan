# Aplikasi Resep Masakan - Kelompok 6

## Deskripsi
Aplikasi Resep Masakan merupakan aplikasi berbasis mobile yang dikembangkan menggunakan Flutter untuk membantu pengguna menemukan inspirasi resep makanan dan minuman, lengkap dengan bahan-bahan serta langkah-langkah pembuatannya.

## Fitur Aplikasi
- Login dan Registrasi
- Halaman Utama
- Pencarian Resep
- Filter Kategori Masakan
- Filter Tingkat Kesulitan
- Detail Resep
- Resep Favorit
- Halaman Tentang Kami

## Teknologi yang Digunakan
- Flutter
- Dart
- Provider

## Tujuan
Memudahkan pengguna mencari inspirasi masakan dan mempelajari cara memasak melalui aplikasi mobile yang praktis dan mudah digunakan.
